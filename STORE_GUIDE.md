# Deploy guide — Streamlit + GitHub Pages + Microsoft Store

Same project, three places:
1. **Streamlit Cloud** → the real app (live URL for PromptWars).
2. **GitHub Pages** (`docs/` folder) → installable PWA shell + privacy/terms pages.
3. **Microsoft Store** → the PWA shell packaged as MSIX with PWABuilder.

> If your Streamlit URL is not exactly `https://utsav-ai-qcbbvwralbmn2krnpq8rfs.streamlit.app`, replace it in: `docs/index.html`, `utsav/export.py` (`APP_URL`) and `README.md`.

## 1. GitHub repo (one command)

From inside the unzipped `utsav-ai` folder (needs GitHub CLI logged in):

```bash
git init -b main && git config user.name "Kanak Prabhakar" && git config user.email "kanakprabhakar72@gmail.com" && git add . && git commit -m "Utsav AI v1.0 — GenAI event planner" && gh repo create Kanak234/utsav-ai --public --source=. --push
```

## 2. Streamlit Community Cloud

1. share.streamlit.io → **Create app** → repo `Kanak234/utsav-ai`, branch `main`, file `app.py`.
2. **App URL**: type `utsav-ai` (gives `utsav-ai.streamlit.app`).
3. **Advanced settings → Python 3.12 → Secrets**: paste
   ```
   GEMINI_API_KEY = "your key from aistudio.google.com/apikey"
   ```
4. Deploy. Open the app, create one plan, check the Ideas tab says **Generated by Gemini**.

## 3. GitHub Pages (PWA shell)

Repo → **Settings → Pages** → Source: *Deploy from a branch* → `main` / `/docs` → Save.
After ~1 min: `https://kanak234.github.io/utsav-ai/` opens the planner inside the shell and `…/privacy.html` works.

## 4. Microsoft Store (MSIX via PWABuilder)

1. **Partner Center account**: storedeveloper.microsoft.com → sign up as *Individual* (check the current fee on the signup page). Reserve the app name **Utsav AI** (Apps and games → New product → MSIX or PWA app).
2. In Partner Center open the product → **Product identity** and copy: *Package/Identity/Name*, *Publisher*, *Publisher display name*.
3. pwabuilder.com → paste `https://kanak234.github.io/utsav-ai/` → **Start**. The report card should be green for Manifest and Service Worker.
4. **Package for stores → Windows → Generate package** → fill the three Product identity values → Download zip. It contains `.msixbundle` + `.classic.appxbundle`.
5. Partner Center → **Packages**: upload the `.msixbundle`.
6. **Store listing**: description from README, screenshots (take 3–4 of the app at 1366×768 or larger), logo `docs/icons/store-logo-300.png`, category *Lifestyle*.
7. **Properties → Privacy policy URL**: `https://kanak234.github.io/utsav-ai/privacy.html`.
8. **Age ratings** questionnaire → submit. Certification usually takes 1–3 days.

## Checklist before publishing (legal & trust gate)

- [x] Privacy policy · Terms · Cookie policy · Refund policy (`docs/privacy.html`, `docs/terms.html`)
- [x] Data collected is disclosed · third-party services listed (Streamlit, Gemini, GitHub Pages)
- [x] No cookies needing consent (none set by us) · no forms collecting personal data
- [x] Alt text, contrast ≥ 4.5:1, keyboard-friendly form, clear buttons
- [x] No fake reviews/claims · original icons only · no secrets in frontend
- [x] HTTPS everywhere · meta/OG tags · favicon · sitemap + robots · custom 404 · offline page
- [ ] Replace `assets/logo-mark.svg` with your real KP orbit logo before pushing
